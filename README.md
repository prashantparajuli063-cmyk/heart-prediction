# ❤️ Heart Disease Risk Prediction

A machine learning project that predicts the risk of heart disease using patient health information.

The project includes data analysis, preprocessing, multiple machine learning models, and an interactive Streamlit web application.

## 🚀 Features

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data cleaning and preprocessing
- 🔤 Categorical feature encoding
- 📏 Feature scaling using StandardScaler
- 🤖 Comparison of 5 machine learning models
- ❤️ KNN-based heart disease prediction
- 🌐 Interactive Streamlit web application
- 💾 Saved model using Joblib
